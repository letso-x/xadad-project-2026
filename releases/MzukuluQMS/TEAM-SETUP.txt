MZUKULU QMS — TEAM SETUP
========================

This package has NO passwords in it (for security). You add them once.

1. Extract this folder anywhere (Desktop is fine).
2. Open  database.config  in Notepad:
   - Replace  ASK_SAKHILE_FOR_PASSWORD  with the shared database password
     (ask Sakhile for it privately — it is never put in git).
   - Save.
3. (Only if you want to send/receive MFA codes) Open  email.config  and fill in
   a Gmail address + 16-char Gmail App Password. Otherwise leave it; admins skip MFA.
4. Double-click  Install.bat  (SmartScreen: More info -> Run anyway).
5. Launch from the "Mzukulu QMS" desktop icon.

Sign in with your email + password. If you don't have an account, click
"Create an account" on the login screen.

Requires Windows 10/11 and an internet connection.
